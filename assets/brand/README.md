# Boltrig brand assets

This directory records the production assets derived from the approved
`AI Product Logo Design` package supplied on 2026-08-15.

- In product and site chrome, use the uppercase `BOLTRIG` wordmark alone.
- The wordmark is Archivo ExtraBold (800) with `-0.02em` tracking.
- Reserve the concentric mark for standalone placements such as app icons and
  favicons. Do not place it beside the wordmark inside the product.
- Installed app, PWA and touch icons use the three-ring redraw on ink `#04060D`, with pale rings
  `#F2F7FC` and the cyan core `#3DD3F0`.
- Browser favicons use the one-ring redraw and cyan core.
- Social cards use the wordmark alone, matching the in-site rule.

`Archivo-Boltrig-ExtraBold.woff` is a glyph-subset of Archivo at weight 800
and normal width. Archivo is distributed under the SIL Open Font License; see
`Archivo-OFL.txt` and the repository third-party notices.

The subset was built from Google Fonts commit
`352f6b7d9d6cc4fa9e242b931291d31b21a6dc84`; its SHA-256 is
`adbd9a15f156d07873b7a43d9ab906219e3cf782022f9b13e42bbc527c583319`.
