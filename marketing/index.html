Governance that holds up under audit.

⚙

Human-in-the-loop, by default

High-consequence actions pause for a person. Approvals are single-use, verb-bound, and can never be self-approved or replayed across calls.

🔗

Tamper-evident audit

Every action writes exactly one hash-chained, HMAC-keyed row. Reorder, drop, or edit anything and re-deriving the chain fails - the log proves itself.

🗃

Tenant isolation at the database

Row-level security enforced inside Postgres, not just in app code. An unscoped query returns zero rows - fail-closed, defence in depth.

🛡

Credentials never leak

Secrets are resolved inside the kernel for one adapter call and never returned to an agent or written to the audit. The store holds references, never plaintext.

⚡

Least-privilege by design

A caller's authority is the intersection of its grants and its scope, re-checked on every call. A token can never exceed the user behind it.

📊

Cost and rate budgets

Per-scope token and spend budgets enforced at the chokepoint, all-or-nothing, so a runaway agent stops at the limit instead of after it.
